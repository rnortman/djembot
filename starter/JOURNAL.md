# Learning journal

A running record of the student's progress, handed from one instructor
session to the next. Read it at the start of a session, after `CLAUDE.md`;
add to it as you go and at the end. Newest session at the bottom of
*Sessions*. The tool changes between versions: check `CLAUDE.md` for what
is new before relying on *Tool notes*.
